# 오픈소스와 라이선스

Free Rider는 **모든 공식 기능을 무료로 제공하는 오픈소스 API 클라이언트**입니다. 기능을 Pro, Premium, Team, Enterprise 같은 유료 등급 뒤에 두지 않는 것을 공식 프로젝트 정책으로 삼습니다.

## 라이선스

Free Rider는 **GNU Affero General Public License v3.0 only (`AGPL-3.0-only`)**로 배포됩니다.

AGPL-3.0은 소프트웨어를 사용하고, 수정하고, 재배포할 수 있는 오픈소스 라이선스이며 상업적 사용도 허용합니다. 다만 수정한 버전을 배포하거나 네트워크를 통해 사용자에게 제공하는 경우에는 AGPL의 소스 공개 조건을 따라야 합니다.

정확한 법적 조건은 저장소의 원문이 우선합니다.

- [LICENSE 전문](https://github.com/dohyeon-kr/free-rider/blob/main/LICENSE)
- [AGPL-3.0-only SPDX 정보](https://spdx.org/licenses/AGPL-3.0-only.html)

## All Free 정책

라이선스와 별개로, **공식 Free Rider 프로젝트와 공식 릴리스는 모든 제품 기능을 무료로 제공합니다.**

- 유료 전용 기능 없음
- 기능 잠금이나 인위적인 사용량 제한 없음
- 공식 데스크톱 릴리스 무료 제공
- 소스 코드 공개 유지
- 후원이나 유료 지원은 가능하지만 제품 기능을 별도로 잠금 해제하지 않음

자세한 내용은 저장소의 [All Free Policy](https://github.com/dohyeon-kr/free-rider/blob/main/ALL_FREE.md)를 참고하세요.
